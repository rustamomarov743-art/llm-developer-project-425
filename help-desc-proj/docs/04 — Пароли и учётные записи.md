# 04 — Пароли и учётные записи

## Требования к паролям

Пароль корпоративной учётной записи должен быть уникальным и не использоваться в других сервисах.

Запрещается передавать пароль коллегам, руководителю или сотрудникам IT-службы.

IT-служба никогда не запрашивает пароль пользователя по электронной почте.

## Многофакторная аутентификация

Для критичных корпоративных систем должна использоваться многофакторная аутентификация.

При получении подозрительного запроса на подтверждение входа пользователь не должен подтверждать операцию.

## Утеря доступа

Если пользователь подозревает компрометацию пароля, он должен немедленно изменить пароль и сообщить в IT-службу.

При невозможности изменить пароль необходимо создать заявку в IT Service Desk.

## Сервисные учётные записи

Сервисные аккаунты не должны использоваться для обычной работы сотрудников.

Секреты сервисных аккаунтов хранятся в корпоративном менеджере секретов.

Запрещается хранить пароли и API-токены непосредственно в исходном коде.
