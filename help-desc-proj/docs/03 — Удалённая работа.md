# 03 — Удалённая работа

## Общие правила

При удалённой работе сотрудник обязан иметь стабильное интернет-соединение и использовать корпоративный компьютер.

Подключение к внутренним ресурсам выполняется через корпоративный VPN.

## Рабочее место

Рабочее место должно обеспечивать конфиденциальность корпоративной информации. Не рекомендуется работать с корпоративными данными в общественных местах.

Экран компьютера необходимо блокировать при каждом уходе от рабочего места.

## VPN

Если VPN недоступен, сотрудник должен обратиться в IT-службу.

Запрещается использовать сторонние VPN для доступа к внутренним корпоративным ресурсам без согласования с IT-службой.

## Информационная безопасность

Нельзя передавать корпоративные документы через личную электронную почту или личные облачные хранилища.

Рабочие файлы должны храниться в корпоративном файловом хранилище.

## Оборудование

При работе из дома сотрудник отвечает за сохранность выданного оборудования.
