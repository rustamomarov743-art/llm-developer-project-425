# 02 — Отпуск и отсутствие сотрудников

## Оформление отпуска

Сотрудник должен согласовать даты отпуска с непосредственным руководителем до подачи заявления.

После согласования информация об отпуске заносится в корпоративный календарь.

## Передача задач

Перед отпуском сотрудник должен:

1. проверить незавершённые задачи;
2. определить задачи, которые нельзя отложить;
3. назначить ответственного за срочные вопросы;
4. сообщить коллегам о периоде отсутствия.

## Автоматический ответ

На период отпуска рекомендуется включить автоматический ответ корпоративной почты.

В автоматическом ответе указываются даты отсутствия и контакт сотрудника, который заменяет отсутствующего.

## Болезнь

При невозможности выйти на работу сотрудник уведомляет руководителя как можно раньше.

Рабочие задачи передаются коллегам по согласованию с руководителем.

## Удалённая работа

Правила уведомления об отсутствии одинаковы для офисных и удалённых сотрудников.
